# Vigenere Cipher
## - A project made by Carter Jordan using Java Swing
## About the Cipher
- A Vigenere Cipher uses a secret key to encrypt or decrypt the message. Once a key is in place, the letters of the key match up with the letters of the message. The key can loop infinitely if needed.
- ![Project Image](https://i.ytimg.com/vi/SkJcmCaHqS0/mqdefault.jpg)
## Contents:
### - Input
- Type the message into the input box.
### - Output
- The encrypted/decrypted message is displayed.
### - Encrypt
- Encrypts the current message with the key.
### - Decrypt
- Decrypts the current message with the key.
### - Clear
- Erases everything so you can enter new pieces.
### - History
- Shows past encryptions/decryptions.
